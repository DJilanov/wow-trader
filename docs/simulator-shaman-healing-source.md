## Direct-spell acquisition boundary

The broader Shaman source work now owns
`infra/simulator/shaman-healing-eligibility.mjs`. Its
`createShamanHealingSpellPolicy({ classSource, books })` builds the full action
policy. The direct component composes that API through the separate
`infra/simulator/shaman-direct-healing-eligibility.mjs` module:

- `eligibleShamanDirectRanks(policy, options)` retains every permitted direct
  downrank at the requested level. Callers must explicitly acknowledge that the
  retained client candidates are conditional; the default returns no spells.
- `assertShamanDirectPriorityEligibility(policy, spellIds, options)` rejects
  priorities outside that domain before a study can run.

The actual learning records link **Healing Wave rank 10 (25357)** to **Tablet of
Healing Wave X (21291)**, which the installed historical Classic reference places
in AQ20. This is not verification of Forever's live acquisition behavior. The
conservative nonraid reference policy excludes that rank, leaving **fifteen
conditional direct ranks** at level 60. Chain Heal remains in the source inventory
but cannot enter the direct component's priority domain. Riptide, totems, unknown
IDs and ranks above the selected level are also rejected.

The pure component controls above deliberately test all sixteen direct spell
records, including the book rank, without asserting ownership. A future numerical
study must apply its declared acquisition policy separately. Three direct-domain
regressions pass alongside the five full-policy regressions. They cover these
distinctions, downranks, level gates, explicit candidate acknowledgment, talent
ownership and mixed/unresolved source rejection:

```sh
node --test infra/simulator/shaman-direct-healing-eligibility.test.mjs infra/simulator/shaman-healing-eligibility.test.mjs
```

The earlier direct-only policy draft was superseded by that broader source work.
Its old 25-test log is retained as historical evidence; the direct component's
current guard has its own file and composes the full policy without replacing it.

The current combined run passes **29 tests** (ten shared acquisition, eight basic
source, three rendering, five full-policy and three direct-domain contracts).
Its raw output is retained at
`optimization/healer-model-admission-v1/shaman-foundation-contracts-20261025T0353.log`
