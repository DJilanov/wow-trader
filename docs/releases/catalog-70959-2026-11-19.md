# Catalog update recovery — November 19, 2026

Build **70959** is published in production. The live Trader shows **233 profitable
quotes** instead of the catalog-review notice. The market API supplies the same
build's native eligibility for **10,438 equipment items**.

## Causes and permanent corrections

The installed updater contained pnpm hard links to workspace dependency sources.
Three market-source edits changed its sealed bytes, so its integrity check failed
before it could process a new client build. Installation now makes independent
copies before sealing the runtime, and verification rejects shared hard links.
The installed release has 3,854 files and **zero shared hard links**. A regression
test edits a dependency's original source after installation and verifies the
installed contents, executable permissions and integrity remain unchanged.

Once restored, the updater found a legitimate new-data transition: item 7994,
Plans: Orcish War Leggings, became readable. Recipe 9957 resolved from ambiguous
to complete and its required Blacksmithing skill corrected from 1 to **205**.
Its materials, output, cooldown and profession did not change. Previously this
held the entire catalog for review.

The new policy independently verifies direct teaching links and their skill ranks
against checksum-verified native ItemEffect, ItemXItemEffect, SkillLineAbility and
ItemSparse records. Only a previously unresolved candidate whose item was absent
from the old catalog can use this path. Fingerprinted proof, the small-change
budget and unchanged economic fields are required. Existing teaching links
cannot disappear. No item-specific exception or blanket review bypass is used.

Execution failures now attempt a macOS notification, deduplicated until recovery.
Even failures before tool loading identify the actual installed release.
Compatible updates run every five minutes and on build/hotfix changes while the
maintainer Mac is running. Unsupported layouts, unexplained economics changes
and missing source evidence still stop publication.
