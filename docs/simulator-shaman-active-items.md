## Qualified shield primitive

`school-specific-shields.mjs` derives the existing core finite-shield implementation
without changing its frozen parent. `ShieldConfig.AbsorbSchoolMask` uses named
engine flags; zero retains the original all-school behavior. Incompatible pools
are skipped without blocking later compatible pools. Eligible overlapping pools
keep application order. Refresh replaces capacity; expiry and manual deactivation
do not trigger depletion. Depletion callbacks can remove an earlier pool or add
a new one without skipping the newly eligible pool.

`client-school-mask.go` exports `SpellSchoolFromClientMask`. DB2 and engine school
bits are different, so direct casting is incorrect. The converter tests all 128
valid client masks and rejects invalid values. New item integrations must validate
the captured nonzero mask before using it as a restricted shield. A zero client
mask converts to `SpellSchoolNone`; it must not be mistaken for a source claim
that a shield absorbs every school.
